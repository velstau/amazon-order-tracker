# Amazon Order Tracker

amazon.co.jp の注文履歴を読み込み、月ごとの支出・注文内容・配達状況を 1 つの画面にまとめる Chrome 拡張機能です。

- **今月の支出がひと目でわかる**：今月・先月の合計と、直近 12 か月の月別グラフ
- **いつ・何を・いくらで買ったか**：注文の一覧を、月・キーワード・未配達のみで絞り込めます
- **いつ届いたか・まだ届いていないもの**：配達日と配達予定、未配達の一覧
- **開いたときに自動で読み込む**：前回から 1 時間以上たっていれば、最近の注文を自動で読み込みます

Amazon とは関係のない、個人が作った非公式のツールです。

## 入手・導入

Chrome ウェブストアには出していません。紹介ページから zip をダウンロードし、デベロッパー モードの「パッケージ化されていない拡張機能を読み込む」で導入します。手順・注意事項・更新履歴は紹介ページにあります。

**https://vel.works/chrome_ext/amazon_order_tracker/**

このリポジトリをそのまま読み込んでも動きます（リポジトリ直下が拡張のフォルダです）。

## 仕組みと通信

- Amazon には注文履歴を取り出せる公開 API がありません。そこで、ログイン中のブラウザの中から amazon.co.jp の注文履歴ページを読み込んで解析します。パスワードは扱いません
- 通信先は amazon.co.jp だけで、ページを読むたびに 1.5 秒以上の間隔を空けます
- 読み込んだ注文データは、この Chrome の中（IndexedDB）にだけ保存します。外部には送りません
- Amazon のページの作りが変わると読み込めなくなります。直す箇所は `parser.js` の冒頭にまとめてあります

## 開発

ビルドはありません（Manifest V3・素の JavaScript）。

| パス | 内容 |
|---|---|
| `dashboard.*` | ダッシュボード（同期・集計・表示はすべてここで行う） |
| `parser.js` | 注文履歴ページの HTML → 注文データ。Amazon の DOM への依存をここに集約 |
| `sync.js` / `db.js` | 年・ページ送りの取得制御 / IndexedDB |
| `tests/` | Node + jsdom のテスト。実際の注文履歴 HTML（`samples/`）は個人情報を含むので、リポジトリには入れていません |
| `docs/HANDOFF.md` | 設計の判断と経緯 |
| `scripts/release.py` | 配布用 zip を作る |

manifest の `key`（公開鍵）で拡張 ID を固定しています。新しい版を別のフォルダに展開しても、読み込んだ注文データが引き継がれます。
